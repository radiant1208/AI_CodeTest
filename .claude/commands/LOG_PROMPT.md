사용자의 요청에 따라 대화 맥락(Context)을 자동으로 분석하고, 지정된 포맷의 Markdown 문서를 생성하여 프로젝트 디렉토리에 저장해 주세요.

### [실행 프로세스]

1. **대화 내역 분석:** 바로 직전에 이루어진 핵심 개발 단위(또는 사용자 지정 단위)의 프롬프트, AI의 응답, 그리고 사용자의 피드백을 파악합니다.
2. **파일명 생성:** `prompts/` 폴더 하위에 `INDEX_주제.md` 형식으로 생성합니다. (예: `prompts/01_initial_design.md`)
3. **파일 자동 작성:** 프로젝트 디렉토리에 `prompts/` 폴더가 없다면 새로 생성하고, 아래 양식을 정확히 준수하여 .md 파일을 직접 생성/저장합니다.
